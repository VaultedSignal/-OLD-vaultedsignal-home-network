# 🛡️ Secure Media Management Stack (Gluetun VPN)

**VM Host:** VM XXX (e.g., Destiny or Orion)
**Purpose:** Deploy the full *Arr stack and qBittorrent, ensuring all torrent and indexer traffic is securely routed through a dedicated VPN connection (NordVPN via Gluetun).
**File:** `gluetun-media-compose.yaml`

---

## 1. 📋 Prerequisites and Setup

### A. Directory Structure
Create the necessary host directories for persistence and configuration.

\`\`\`bash
# Create base configuration directory for Gluetun volume
sudo mkdir -p /docker/gluetun

# Create configuration directories for all *Arr apps (optional but good practice)
sudo mkdir -p ./config/{prowlarr,sonarr,sonarr-anime,radarr,radarr-anime,huntarr,cleanuparr}

# Ensure the required mount points for qBittorrent are created
sudo mkdir -p <PATH_TO_DOWNLOADS>
sudo mkdir -p <PATH_TO_MEDIA>
\`\`\`

### B. Crucial Host Setup
The host machine must have the **TUN/TAP interface** enabled for the VPN to function.

\`\`\`bash
# Check if the tun module is loaded (should return a number/path)
ls /dev/net/tun

# If the module is missing, load it manually
sudo modprobe tun
\`\`\`

| Variable | Location | Value to Replace | Purpose |
| :--- | :--- | :--- | :--- |
| **PUID** | All client containers | `<YOUR_PUID>` | Primary User ID for file ownership. |

| **OPENVPN_PASSWORD** | `gluetun` | `mmssMbjFzWdJFdxeisWzHTqD` | Your VPN provider password. **(CRITICAL)** |

### B. File Paths
| Variable | Container | Value to Replace | Purpose |
| :--- | :--- | :--- | :--- |
| **Download Path** | `qbittorrent` | `<PATH_TO_DOWNLOADS>` | Host path where torrents are initially saved. |
| **Media Path** | All *Arr apps, `qbittorrent` | `<PATH_TO_MEDIA>` | Host path where final media files are stored. |
| **Local Subnet** | `gluetun` | `192.168.2.0/24` | **Crucial:** Allows the containers to communicate with local services (e.g., your NAS or Portainer UI). |

### A. Deployment
Navigate to the directory containing the `gluetun-media-compose.yaml` file and deploy the stack.

## 4. 🧠 Architecture and Networking

### A. VPN Integration (Network Mode)
The key to this secure setup is the `network_mode: "service:gluetun"` directive used in every client container. 

* This forces the client containers (qBittorrent, Sonarr, etc.) to **abandon their own network stack** and use the **network stack of the `gluetun` container** instead.
* Since `gluetun` is actively connected to the VPN, all outbound traffic from the client containers is automatically encrypted and routed through the VPN tunnel.

### B. Health Check
The `depends_on` block is crucial:
```yaml
depends_on:
  gluetun:
    condition: service_healthy
